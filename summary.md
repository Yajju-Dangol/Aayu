# Aayu AI Doctor - Project Summary

## 1. Native Gemini Live API Integration
- **Bypassed SDK Bundling Bugs**: Initially, the `@google/genai` SDK caused `TypeError` panics and import errors in the Vite frontend. To fix this comprehensively, a native WebSocket connection was established targeting Google's `BidiGenerateContent` endpoint, handling the binary multiplexing perfectly.
- **Audio Output Pipeline (TTS)**: Engineered a robust internal audio system leveraging the browser's `AudioContext`. Audio data emitted from Gemini (24kHz format encoded as Base64 strings) is transparently intercepted, mapped backwards onto asynchronous Float32Arrays, and scheduled consecutively onto speakers with a `nextPlayTime` variable to ensure zero jitter.
- **Live Voice Processing & Resampling (STT)**: Integrated the `navigator.mediaDevices.getUserMedia` MediaStream interface into an interactive `ScriptProcessorNode`. This component natively intercepts chunks of the client's microphone audio flow, mathematically downsamples dynamic browser frequencies entirely down to precise `16kHz Mono PCM` streams, and relays serialized Base64 chunks natively onto the Socket.

## 2. API Schema Debugging and Payload Adjustments
- **Solved MediaChunks Deprecation (`1007` Connection Terminations)**: Replaced deprecated `@google/genai` format parameters ensuring raw strings and binary arrays matched flawlessly. The WebSockets originally terminated instantly upon streaming audio because the schema strictly rejected `realtimeInput.mediaChunks` formatting, which was swapped actively to correct `{ realtimeInput: { audio: { ... } } }` architecture matching modern v1alpha parameters.
- **VAD (Voice Activity Detection)**: To radically enhance UX immersion by speeding up conversational cadence, advanced VAD parameters like `"TURN_INCLUDES_ONLY_ACTIVITY"` and precise padding tolerances (e.g., `silenceDurationMs: 250`) were injected seamlessly directly into `setupMessage.realtimeInputConfig`.
- **Text Activity Overload Fix**: Solved the "silent connection drop" where Gemini wouldn't respond to the initial *"Please start the conversation"* text greeting. Since pure Voice Activity Detection blocked external schema text layers like `clientContent`, the initial triggers were migrated safely entirely onto `{ realtimeInput: { text: ... } }`. 

## 3. Dynamic Application Interface Updates (App.tsx)
- **Live Transcription Splitting**: Rewrote the transcription box mechanism to visibly parse the separate `inputTranscription` and `outputTranscription` components provided by Gemini. Activating the microphone transforms the widget into a beautiful split message layout actively displaying conversational transcripts generated by the `"You"` and `"Aayu AI"` labels dynamically.
- **Microphone Feedback Element**: Added immersive blinking visual elements linking React's recording state securely with the `agent.connect()` and `agent.startMicrophone()` event dispatch pipeline. 
- **PDF Vector Injection Binding**: Integrated Supabase `knowledge.ts` execution strictly enforcing that vectorized Hospital PDF reports (routed through `gemini-embedding-2`) attach locally strictly alongside secure Supabase authentication IDs `user.id` instead of arbitrary `DUMMY_USER_ID` mock data bounds!

## 4. Supabase Authentication & Splash Ecosystem
- **Modern UI Architecture Implementation**: Drafted `LandingPage.tsx` strictly mimicking sleek reference aesthetics containing vibrant lime green (`#E2FF66`) and deep purple backgrounds featuring interactive banners, asterisk graphics, fluid curved vector layouts, and polished marketing points *(Inclusivity, Innovation, Community)*.
- **Lifecycle Authentication Shield**: Built robust event monitoring pipelines internally through `supabase.auth.onAuthStateChange` to actively hook native session events alongside an independent Loading mechanism, locking frontend routes conditionally per instance.
- **Google OAuth Linking**: Built direct authentication logic invoking single-click Supabase redirects connecting flawlessly to Google interfaces.
- **Dynamic Identity Extraction**: Hardcoded mock user artifacts inside the dashboard sidebar *(Aama Thapa & random vectors)* were radically removed and mapped actively toward real dynamic metadata properties pulled straight from session profiles: rendering the live user's Google Name (`user_metadata.full_name`), rendering their live Avatar Image ID (`user_metadata.avatar_url`), and attaching standard Sign-Out routines onto new dynamic interface buttons.

Authenticated users pass automatically through vector-protected application borders accessing their real demographic endpoints, can autonomously click the main recording pipeline natively executing Voice-Activated RAG (Retrieval-Augmented Generation) architectures strictly bounding to their local profile knowledge vectors, mapping a genuine full-tier conversation fluidly without API bottlenecks.
